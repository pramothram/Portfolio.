Farm Profit/Loss Management Website


A web-based farm management application that helps farmers track planting activities, daily farming expenses, harvest income, and automatically calculate their final profit or loss.


Technologies Used


  • HTML5
  • CSS3
  • JavaScript
  • Python
  • Django
  • PostgreSQL
  • Tools - VScode and Git

Features


  • User Registration & Login
  • Farmer Dashboarde
  • Farm/Planting Management
  • Daily Expense Tracking
  • Harvest & Income Entry
  • Profit/Loss Calculation
  • Responsive UI
  • Secure User Authentication
