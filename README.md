# Personal Portfolio Website

A modern and responsive personal portfolio website designed to showcase my skills, projects, certifications, and contact information.

## 🌐 Live Demo

[View the Portfolio Website](https://portfolio-81d3.vercel.app/?utm_source=chatgpt.com)

## 📌 About the Project

This is my personal portfolio website built to present my profile as a developer. The website provides information about my technical skills, projects, achievements, and ways to contact me.

The portfolio is designed with a clean, modern, and responsive user interface so that it works smoothly on desktop, tablet, and mobile devices.

## ✨ Features

* Responsive design for desktop and mobile devices
* Modern and attractive user interface
* About Me section
* Skills and technologies section
* Projects showcase
* Certifications section
* Contact section
* Smooth navigation between sections
* Interactive user experience

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* Git and GitHub
* Vercel for deployment
